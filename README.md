# luna-web

Marketing landing page for **[Luna](https://github.com/NathanOyewole/luna)** — the lightweight gameplay video editor.

## Stack

- Static HTML / CSS
- No build step
- Deploys cleanly on Vercel / Netlify / GitHub Pages

## Local preview

```bash
npx serve .
# or
python3 -m http.server 5173
```

## Deploy

Push to `main` and connect the repo to Vercel (framework: Other, output: root).

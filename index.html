Local-first by design

Your project is an edit decision list — kilobytes, not gigabytes. Frames are decoded only when needed. Heavy work (scrub decode, AI, export) runs in isolated processes so the UI stays responsive.

The idea

Neovim philosophy for video: cheap always-resident state, expensive work delegated. You edit structure, not a pile of decoded frames.
